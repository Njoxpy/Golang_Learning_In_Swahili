# Golang Learning in Swahili

Golang Learning in Swahili ni mradi wa wazi unaotoa masomo, mifano, na mazoezi ya Go (Golang) kwa lugha ya Kiswahili. Lengo ni kufanya mtu aweze kujifunza Go kwa hatua ndogo, kwa ufafanuzi rahisi, na kupitia mifano ya vitendo.

## Malengo ya Mradi

- Kufundisha msingi wa Go kwa Kiswahili.
- Kutoa mazoezi ya Beginner, Intermediate na Advanced.
- Kuwezesha wanaojifunza kuwa Backend Developers au Golang Engineers.
- Kutoa rasilimali za kujifunza kwa mfumo wa hatua kwa hatua.

## Muundo wa Mafunzo

Masomo yamegawanywa katika ngazi tatu:

- **Beginner:** Misingi ya Go kama variables, types, functions, control flow, arrays, maps, structs.
- **Intermediate:** Pointers, interfaces, concurrency, channels, file I/O, testing.
- **Advanced:** Context, concurrency patterns, dependency management, reflection, optimization.

Anza na somo la kwanza hapa:  
**[Introduction](lessons/beginner/introduction.md)**

## Mazoezi

Kila ngazi ina maswali na mazoezi ya vitendo. Angalia sehemu ya _Exercises_ kwenye menyu.
